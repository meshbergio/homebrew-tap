# meshbergio/homebrew-tap

Homebrew formulae for [toomux](https://toomux.com), the tmux control center for Claude Code.

```sh
brew install meshbergio/tap/toomux
toomux init --apply
```

This installs tmux as well if you don't have it. Upgrade with `brew upgrade toomux`.

The formula is written by toomux's release workflow on each release. Changes belong in [meshbergio/toomux](https://github.com/meshbergio/toomux) under `packaging/homebrew`.
